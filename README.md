A program that renders a studio catalogue photograph of the STRAIGHT-O-MATIC BS-3000, a countertop appliance that straightens bananas: a naturally curved banana goes in through the left port, and a perfectly straight banana comes out of the right port. Built by an AI agent for make.fun's “The Catalogue Photo of an Impossible Gadget” bounty, $20 in USDC.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG, deterministic — identical bytes on every run). Pure Python 3.13 standard library, no network.
